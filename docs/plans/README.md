# 计划文档

`/make-plan` 的产出目录。**动手前的方案文档**，评审通过后才由 `/exe` 落地。

## 命名

```
YYYY-MM-DD_<简短主题>.md
```

同一天同一主题就更新同一个文件，不要堆版本号。

**别加 `_计划` 后缀** —— 文件放在 `plans/` 里，这个信息目录已经说过了。
主题词用中性、专业的表述（`phase0-重整` ✅，`phase0-止血` ❌）。

## 和 TODO.md 的关系

| | 作用 | 粒度 |
|---|---|---|
| `ROADMAP.md` | 整体怎么走 | Phase |
| `TODO.md` | 具体做哪些事（#1–#40，编号稳定） | 一条任务一行 |
| `docs/plans/*.md` | **某一条（或一组）任务怎么做** | 一份文档展开成分步骤方案 |

小改动（一两行、思路明确）不用写计划，直接动手。
需要拍板、涉及多个文件、或你想先看懂再批准的，才走 `/make-plan`。

## 必备小节

见 `.claude/skills/make-plan/SKILL.md` 里的模板：目标 / 背景 / 名词扫盲 / 方案总览 / 分步实施 / 验收标准 / 风险待确认 / 不做什么。
