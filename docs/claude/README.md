# 会话记录

每次**有代码改动或技术决策**的 Claude 会话，在本目录追加一条记录。纯提问、纯读代码的会话不用记。

## 命名

```
YYYY-MM-DD_<branch或主题>_会话记录.md
```

同一天、同一 branch 追加到**同一个文件**里，不要每次新建。

## 模板

```markdown
# YYYY-MM-DD · <branch 或主题>

## 背景
这次要解决什么问题，从哪来的（TODO #n / 路线 Phase n / 临时发现）。

## 改动清单
| 文件 | 改了什么 |
|---|---|
| `path/to/file.ts` | 一句话 |

## 决策与理由
做了什么选择、为什么、放弃了什么方案。
若与 PRD「决策记录」现有条目冲突或对其修订，**必须同时回写 PRD**。

## 验证
跑了什么、结果如何（`npm run lint` / `npm run build` / 线上实际点了哪些路径）。
失败的如实写，别只写通过的。

## 发现 / 待办
过程中发现但这次没处理的。
够格进 TODO.md 的就加进去（记得给编号）；只是观察就留在这里。
```

## 为什么要记

这个项目的上下文散在五份文档里，会话记录是**唯一按时间顺序**说清「那天为什么这么改」的地方。
几周后回头看 `git log` 只有「fix」两个字的时候，这里是唯一的线索。
